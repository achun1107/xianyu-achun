# 闲鱼自动化 · 主控仓

把闲鱼「代拍商品上架」这件事做成一条命令的自动化工具。

输入 **`广州 王嘉尔`**，它自己完成：选品 → 出主图 → 写文案 → 填规格 → 发布 → 记录。

---

## 它解决什么问题

闲鱼上架一件代拍商品，手动要做这些：

| 步骤 | 手动耗时 |
|---|---|
| 查大麦场次、城市、开票时间 | 5–10 分钟 |
| 做主图（标题块、日期、价格、风格） | 10–20 分钟 |
| 写标题（30 字）、正文、卡片文案 | 10 分钟 |
| 填分类、规格、库存、所在地、发货方式 | 5 分钟 |
| 发布 + 记录链接 | 2 分钟 |

**一件商品 30–45 分钟。** 这个工具把它压到 **1 分钟**，且文案风格、价格策略、主图版式都是可配置的。

## 核心概念

### 店铺档案（`stores/<店名>.json`）

一件商品长什么样，全在这个文件里：

```jsonc
{
  "分类": { "catId": "50025461", "channelCatId": "202285710" },
  "价格": { "标价": 4, "预算": 50, "加价档": [4, 6, 8] },
  "文案": { "templateIds": [1,2,3,4] },   // 文案池
  "主图": { "styles": [...], "baseImg": "..." },
  "文案池": { "1": "...", "2": "..." }
}
```

**不同的人做不同生意**，所以每个人的档案都不一样 —— 这是设计意图，不是配置项漏了。

### 一句话输入

```
广州 王嘉尔        # 空格分隔
广州王嘉尔         # 直接连写
上海，周杰伦       # 全角逗号
成都/薛之谦        # 斜杠
```

都能解析出「城市 + 明星」。

### 三条红线（写死在代码里）

| 规则 | 位置 |
|---|---|
| 单次咨询成本 ≤ ¥4 | `lib/ad-guard.js` |
| 咨询量上限 4 / 订单量上限 35 | 同上 |
| 永不碰「擦亮宝贝*」计划 | `tools/ad-*.js` |

## 依赖

| 依赖 | 用途 |
|---|---|
| Node.js 18+ | 运行时 |
| `xianyu-playwright-service`（独立仓） | 8093 端口，管登录态和浏览器 |
| `xianyu-monitor`（独立仓） | 发布与广告的执行层 |
| museav CLI（可选） | 出专属底图；没有就用大麦底图 |

**三个目录必须并排**：

```
某处/
  ├─ xianyu-achun/               ← 本仓
  ├─ xianyu-playwright-service/  ← 8093 服务
  └─ xianyu-monitor/             ← 发布执行
```

## 已知限制

| 现象 | 说明 |
|---|---|
| 一个闲鱼号只能一台机器 | 平台规则 |
| 每个店要单独扫码 | 登录态按店铺隔离 |
| 报错里有 `-9` | 审核中，10–30 分钟转正，**别重复发** |
| 首次安装 5–15 分钟 | 在下 Chromium 内核 |
| 8093 空闲 20 分钟回收上下文 | 正常，点「预热浏览器」就回来 |
