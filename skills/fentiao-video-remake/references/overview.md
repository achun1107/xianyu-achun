## 1. 结构 (Structural)

### 类型
实操手册型方法论（视频复刻 SOP）

### 一句话主旨
复刻一条爆款短视频，复制的是它的**结构与节奏**（几刀、什么时候切、版式坐标、声音配方），而不是它的画面本身；逆向要取证到坐标级，出片要走可复跑的本地流水线。

### 骨架 (主要论点及其关系)

1. **逆向分两轮**：先工具拆解（镜头/画面来源/包装层/声音），再像素级实测（版式坐标、配色、字号）——工具给"是什么"，实测给"怎么摆"。
2. **最该保留的是节奏**：切镜密度与口播/语义的关系（三种节奏结构：AI小凯全程 2s 快切、Lindsay 两个长镜+一处 0.5s 等距卡点、Scrapling 前 16.4s 一镜到底演示段才切）。
3. **同作者同模板**：参考作者所有视频共用"实拍 + 左上黄字两行标题 + 底部黄字字幕 + BGM"模板，模板本身就是可复刻的配方。
4. **素材获取有确定路径**：抖音无水印原片走 web aweme/detail 页面内签名，play_addr 即无水印流；素材带烧录字是常态，组装前要挑干净片段。
5. **出片走本地可复跑管线**：分镜 JSON → 模板渲染 → 编译期校验 → 本地渲染 → 导出成片 + 文案；描边等渲染细节有确定的坑与解法。
6. **验收靠对比**：把成片帧与参考帧并排放，逐项对坐标、配色、亮度。

**论点之间的关系**: 递进（取证 → 提炼 → 素材 → 出片 → 验收）

### 作者要解决的核心问题
拿到一条别人的爆款视频后，如何**不靠肉眼猜**地把它拆到可复刻的程度，并用自动化流水线批量产出同结构的新片。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 结构复刻 | 复制切镜节奏 + 版式坐标 + 声音配方，不复制画面内容 | 常识"复刻"指尽量做成一模一样 |
| 包装层 | 字幕/花字/标题/贴纸等后期叠加，与画面分离、单独叠 | 常识"字幕"只指台词字 |
| 一刀 | 一个连续镜头（scene 检测切点之间） | 剪辑行话"一刀"含义相同，但这里用作量化单位（刀/分钟） |
| 像素级实测 | 逐帧扫像素求 bbox/色值/字高，而不是看图估 | 与"目测版式"相对 |
| 烧录字 | 烧进画面像素的后期文字，无法单独关掉 | 与外挂字幕（软字幕）相对 |

### 核心命题 (用自己的话)

1. 工具拆解只能告诉你"实拍/代码渲染"，版式的坐标、字号、描边厚度必须自己扫像素。
2. 参考片的可复用资产是一份**坐标 + 节奏 + 声音**的规格书，不是视频文件本身。
3. 复刻时素材可以换（同题材干净实拍），但标题位置、字幕位置、颜色语义不能换。
4. 渲染器的实现细节（如 hypit 描边图层顺序）会直接决定成败，坑要记录成配方的一部分。

### 论证链
rea-video 拆解报告（镜头/声音/包装统计）→ 结构分析（三种节奏结构、同作者模板归纳）→ 像素实测（坐标/色值表）→ 本地流水线落地经验（描边顺序、无水印提取）→ 对比图验收。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 单一平台（抖音）、单一垂类（钢材/五金）的样本；结论是否迁移到其他平台/垂类未验证。
- 依赖工具链（rea-video/hypit/ffmpeg）的当日版本行为，工具升级可能失效。

### 作者的立场盲点
- 只讲"怎么像"，不讲版权边界：参考素材与 BGM 的使用责任留给使用者。
- 以工程可复现为先，对"内容本身好不好"（文案钩子强弱）着墨少。

### 未被证明的假设
- 假设"结构 = 可复用资产"足以带来同类表现（未做 A/B 验证）。
- 假设同作者所有视频共用同一模板（样本内成立，全站未验证）。

### 最强反对意见
复刻得再像，投的是新账号新素材，流量差异主要来自选题与钩子，版式复刻的边际收益可能远小于文案与选题的边际收益。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**
