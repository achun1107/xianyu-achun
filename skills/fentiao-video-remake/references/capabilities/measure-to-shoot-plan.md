# 从测量到拍摄方案的转换与重拍执行

## R — 原文 (Reading)

> 同一场景的镜头集中拍完再换场景；场景内先拍大景别再拍特写，不用重新布光。每条前后多留约 1s 余量。
>
> — source.md · 第一部分「复刻方案 · 拍摄场次」（L149）

> 机位 近景 · 移动机位（稳定器/手持平移） · 固定：镜头 #1，成片 13.5s，建议拍 15.5s
>
> — source.md · 第一部分「拍摄场次」S1 场次卡（L153）

---

## I — 方法论骨架 (Interpretation)

测量表（景别/机位/打光/调色/形式六项 + 光比色温）本身不是拍摄指令，这一段做的事是把"观测结论"翻译成"到现场能照着执行的东西"。转换的产出有五件：复刻拍摄方案五项（形式/取景/机位/布光/剪辑）、器材清单、异常项注意、场次组织规则、每个分镜的执行方式。
器材与注意是配套的：主参数（正面柔光、3000–4000K）只管大方向，真正的偏差藏在三条异常项里——主体下半部偏亮（下方反光）、主体与背景色温不一致（混合光源）、背景明显虚化（浅景深），每条都要落成处理动作。
场次规则解决现场效率：同场景集中拍完再换、场景内先大景别后特写（省去重新布光）、每条前后各留约 1s 余量——所以"成片 13.5s 的镜头，建议拍 15.5s"。
执行方式是三分支：有拍摄条件 → 按场次卡重拍；无拍摄条件 → 才用 AI 图生视频近似（以首帧为参考）；画面里含真实素材（录屏/截图/照片） → 必须向素材方索取原文件，模型替代不了。
测量值自带偏置（无人脸时景别是估算、平台转码压暗部使读数偏保守），必须随卡标注，不能当原始拍摄真值用；实拍判定本身低置信时，先核对取证侧的不确定点再定分支。

## A1 — 应用示例 (Application Example)

### 示例 1: S1 场次卡演算（原书例题）
- **类型与来源**: 原书例题（案例 c12，worked_example）；source.md L74–95、L143–159
- **问题/输入**: 逐项测量表——景别近景、移动机位（稳定器/手持平移）、柔光（光比约 1.3:1，相差 0.4 档）、色温约 3000–4000K、自然调色、形式手持拍物品；参考片单镜成片 13.5s
- **方法的使用**: ①翻译为方案五项（形式：手持拍物品 / 取景：近景为主 / 机位：移动机位 / 布光：正面柔光——大柔光箱放镜头后方或环形灯 / 剪辑：单镜 13.5s 不切）②配器材（镜头后方或桌面正上方大柔光灯、两盏对称 45°、白桌面或白卡反光）③回填三条注意（下半部偏亮、混合光源色温不一致、背景虚化）④场次组织（同场景集中、先大景别后特写、每条约留 1s 余量）⑤时长演算：13.5 + 1 + 1 = 15.5s ✓ ⑥光比换算：log₂(1.3) = 0.379 ≈ 0.4 档 ✓（与 L76"相差 0.4 档"一致）
- **结论**: 测量结论 → 可拍指令的完整转换；S1 场次卡含布光/机位/时长三要素
- **结果**: 例题结果即原书 S1 场次表本身；真实是否开拍、成片效果如何——原书未说明

### 示例 2: 执行分支的落位
- **类型与来源**: 原书明文分支规则（source.md L155–159、L194）
- **问题/输入**: 镜头 #1 整个画面是实拍视频素材（自己拍的还是影视片段，看图确认），成片 13.5s
- **方法的使用**: 分支判定——有拍摄条件按 S1 重拍；无拍摄条件才 AI 图生视频（首帧为参考）；真实素材"模型生成替代不了" → 向素材方索取原文件
- **结论**: 三分支互斥，真实素材项优先级最高（索取原文件不因 AI 能力而豁免）
- **结果**: 原书给出分支规则与 S1；实际执行结果未说明

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 参考片的测量表已经出来了，要开拍，但不知道怎么排场次、配灯、留多少余量
2. 多个镜头要组织拍摄顺序（哪些集中拍、什么时候换场景/换布光）
3. 每条要拍多久说不清——成片时长和素材时长怎么换算
4. 要判定每个分镜走哪条路：重拍 / AI 图生视频 / 向素材方要原文件
5. 拍出来的画面光感和参考对不上，怀疑是异常项（反光/混合光/虚化）没处理

### 语言信号 (用户的话里出现这些就应激活）

- "测量完了怎么拍 / 拍摄方案 / 场次表 / 每条拍多久"
- "重拍还是 AI 生成 / 要不要重新布光 / shooting plan / shot list / scene breakdown"
- "reshoot or AI / lighting recipe / 按参考片拍一条"
- "布光配方 / 光比多少档 / 时长余量 / take length"

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `reference-breakdown-two-round`（V-01）的区分: V-01 是测量与取证的产出方（给出事实与置信度），本卡是消费方（把事实翻译成拍摄指令）；没测量表先去 V-01
- 与 `storyboard-local-pipeline`（V-06）的区分: V-06 是合成/包装的渲染出片线，本卡是实拍素材分支；成片最终合流到 V-06 铺包装层
- 与 `remake-acceptance-diff`（V-07）的区分: V-07 验收成片与参考的对齐，本卡管拍摄前的方案与执行方式，拍完才进验收
- 与 `layout-pixel-spec`（V-02）的区分: V-02 量的是版式坐标（文字怎么摆），本卡用的是拍法/打光/机位测量（画面怎么拍）

## E — 可执行步骤 (Execution)

**必需输入**: ①六项测量表（景别/机位/打光含光比与色温/调色/形式，缺任一项 → 先回测量环节，不猜值）②每镜成片时长 ③拍摄条件（有/无）④真实素材清单（录屏/截图/照片/嵌入视频）⑤V-01 不确定点清单（实拍置信、测量偏置标注）。**输出契约**: 方案五项 + 器材清单 + 三条注意的处理动作 + 场次卡（布光/机位/时长三要素齐全）+ 每个分镜的执行方式（重拍 / AI 图生视频 / 索取原文件 三选一）。计算约定：建议拍时长 = 成片时长 + 2s（前后各约 1s，源自 L149"每条前后多留约 1s 余量"）；光比转档位 = log₂(光比)，保留 1 位小数（演算值 log₂(1.3)=0.379≈0.4 档，与原书一致）。

1. **翻译方案五项 + 配器材 + 回填三条注意**
   - 完成标准: 形式/取景/机位/布光/剪辑五项齐全；器材清单含具体灯位（镜头后方或桌面正上方大柔光灯、两盏对称 45°、白卡反光）；三条异常项（下半部偏亮、混合光源、背景虚化）逐条有处理动作而非仅抄注意事项（ce16）

2. **组织场次**
   - 完成标准: 输出场次表，满足同场景集中拍完再换、场景内先大景别后特写、每条前后留约 1s 余量

3. **演算每镜时长**
   - 完成标准: 每镜给出"成片 X s → 建议拍 Y s"，Y = X + 2；可用原书数据复算：13.5 + 1 + 1 = 15.5s

4. **换算光比/色温并标注测量偏置**
   - 完成标准: 光比给出档位换算（1.3:1 ≈ 0.4 档）；卡上显式标注偏置——无人脸景别为估算、平台转码压暗部使读数偏保守、测量与看图冲突时两者并列（ce17）

5. **裁定每个分镜的执行方式**
   - 完成标准: 每个分镜落一个分支：有拍摄条件 → 按场次卡重拍；无拍摄条件 → AI 图生视频（首帧为参考）；含真实素材 → 向素材方索取原文件（模型替代不了）
   - 判停条件: 实拍判定低置信（如次选 ai_video、置信 60%）→ 先核 V-01 不确定点再定分支，不凭低置信结论开拍；测量表缺失 → 停在步骤 0（回测量），不补造数值

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 没有测量表就直接开拍 —— 本卡不产生测量，先走 V-01（工具拆解）与像素级实测
- 纯合成/包装出片、无实拍需求 —— 那是 V-06 的渲染线；本卡只处理实拍素材分支
- 成片已经出来、只关心像不像 —— 那是 V-07；本卡的终点是"可执行的拍摄指令"，不是验收结论

### 作者在书中警告的失败模式

- **ce16 只抄主参数、漏三条异常项** —— 只对齐"正面柔光、3000–4000K"，不处理下方反光/混合光源/背景虚化，光感对不上；或把参考片的缺陷当目标复现而不自觉（L92–94）
- **ce17 拿转码后的测量值当真值** —— 平台转码压暗部使读数系统性偏保守，按测值布光拍出来比参考更平；测量与看图冲突时只引用其中一个（L109）
- **低置信分支误判** —— 实拍判定仅 60% 置信（次选 ai_video）时直接定分支，可能选错重拍/AI 路线（对应 V-01 不确定点，L169–171）

### 作者的盲点 / 时代局限（BOOK_OVERVIEW「3. 批判」）

- 单一平台（抖音）、单一垂类（钢材/五金）样本，拍摄方案的迁移性未验证；工具链当日版本行为影响测量口径
- 测量占比的分母口径（按帧还是按时长）未定义（P-6），本卡直接消费测量结论、不复算占比
- 假设"结构 = 可复用资产"足以带来同类表现（未做 A/B 验证）——拍得再像，不保证有流量
- 只讲"怎么像"，不讲版权边界：真实素材（尤其影视片段）的使用责任留给使用者

### 容易混淆的邻近方法论

- "照着参考片重拍"≠"像素级复刻版式"：本卡管拍法与布光，版式坐标归 V-02/V-06，两者的验收分别落在 V-07 的不同项
- AI 图生视频是**无拍摄条件时的降级分支**，不是首选；把它当默认路线会绕过本卡的场次与布光设计
