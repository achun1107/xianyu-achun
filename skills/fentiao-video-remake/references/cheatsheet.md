# 决策规则速查 — 抖音「钢材分条」参考片的逆向与复刻方法论

| 能力 | 一句话规则 |
|---|---|
| 参考片两轮逆向取证 | 工具拆解给"是什么"，像素实测给"怎么摆"，每个结论带置信度和复核路径。 |
| 像素级版式实测与坐标规格 | 没有 bbox/色值/字高三件套就不算量过版式，换分辨率按百分比换算。 |
| 切点节奏结构提炼 | 三选一归类节奏结构（全程快切/长镜+单点卡点/前长后短），从切点分布反推原始剪辑做法。 |
| 声音配方复刻 | BGM 来源判定走确认路径不把先验当结论，音效按证据等级卡在文字/贴纸出现帧上。 |
| 抖音无水印素材提取与烧录字预处理 | 页面内签名取 play_addr 无水印流，抽帧查烧录字，有字就挑片段或换素材。 |
| 分镜驱动的本地出片流水线 | 环境就绪 → 分镜 JSON → 模板渲染（描边 Stroke 在 Fill 前）→ 校验 → 先 30 秒样片过审再铺全片。 |
| 成片并排逐项验收 | 成片帧与参考帧并排对坐标/色值/字高/画幅，超阈值打回，不凭观感放行。 |
| 测量到拍摄方案的转换 | 六项测量翻成拍摄五项+器材+场次卡，重拍优先、AI 图生视频兜底、真实素材索取原文件。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
